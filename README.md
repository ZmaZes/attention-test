# Attention Test
A test to test your attention. I think, are you even listening?

The goal is to click space every time you see a letter that is **not** x.
This should either be farily easy or very difficult.

### Keyboard Shortcuts
|Key|Function|
|---|--------|
|Space/Click|Confirm that the letter is not an X|
|R|Restart|
|P|Pause|
|N|Toggle Numbers|
|M|Toggle Sound|
|G|Toggle Graph|
|Shift+S|Show extra info (S to hide)|
